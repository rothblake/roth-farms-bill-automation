Privacy Policy

Roth Farms Bill Automation · Last updated: June 12, 2026

This policy explains how the private, internal application "Roth Farms Bill Automation" (the "Software") handles data. The Software is operated solely by Roth Farms for our own use.

What data the Software handles

The Software processes bill documents we provide (images or PDFs of vendor invoices and statements) and the QuickBooks Online data needed to record them — for example vendor names and addresses, expense accounts, classes, dates, invoice numbers, and amounts. It also stores an Intuit OAuth access/refresh token so it can connect to our QuickBooks companies.

Where data goes

The Software runs on our own computer. Data is shared with only two external services, and only to perform the task:

  • Intuit / QuickBooks Online — bill and vendor data is sent to Intuit's API to create and verify bills in our own QuickBooks companies, under Intuit's Developer Terms of Service.
  • Anthropic (Claude API) — each bill document is sent to Anthropic's API to read the text and extract the bill's fields. Anthropic processes the document to return the extracted data and does not receive our QuickBooks credentials.

Data is not sold, rented, used for advertising, or shared with any other third party.

Storage and security

Bill documents and run reports are stored locally on our own machine. Intuit OAuth tokens and the application's secret keys are stored in a local configuration file that is excluded from version control and from cloud syncing. All connections to Intuit and Anthropic use encrypted HTTPS/TLS. The Software is used by a single operator and does not expose a public service.

Retention and deletion

Because data stays on our machine, we control retention directly. Source documents and reports can be deleted at any time, and QuickBooks access can be revoked from the Intuit account's Connected Apps settings, which invalidates the stored tokens.
